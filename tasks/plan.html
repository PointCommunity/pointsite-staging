Implementation Plan

Dependency graph

Live Actions evidence → failing compatibility test → exact Builder v8 site-kit sync → full local gates → staging PR → exact-merge Actions and live verification.

Architecture decisions

  • Repair staging, because the content-only publisher is an intentional security boundary.
  • Copy from a clean Builder origin/main worktree, not the unrelated dirty Builder branch.
  • Preserve the current revision 83 content and media exactly.

Risks and mitigations

  • Candidate overwrite: compare content/media hashes before and after.
  • Incomplete dependency inventory: add v6-v8 helper modules to the sync script and prove the full build works.
  • False local confidence: require exact-head GitHub Quality and Deploy staging results.

Checkpoint

Do not merge until focused red/green evidence and all local workflow-equivalent gates pass. Do not report resolution until the merged commit’s two workflows are terminal and successful.
